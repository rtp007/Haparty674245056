# Ha Party — ระบบค้นหาและจัดทีมสำหรับผู้เล่นเกม

Ha Party เป็น Web Application ที่ช่วยให้ผู้เล่นเกมค้นหาเกม ค้นหาปาร์ตี้ที่เปิดรับสมาชิก สร้างปาร์ตี้ และเข้าร่วมเล่นเกมกับผู้เล่นคนอื่น โดยมีระบบสมาชิกและระบบผู้ดูแล (Admin)

## 1. เทคโนโลยีที่ใช้

- **Front-end:** HTML5, CSS3, JavaScript และ DOM
- **Back-end:** Node.js และ Express.js
- **Database:** MySQL
- **การเชื่อมต่อเว็บ:** RESTful API, Routing, HTTP Request/Response
- **การจัดการสถานะผู้ใช้:** Session และ Cookie
- **แพ็กเกจสำคัญ:** `express`, `express-session`, `mysql2`, `bcrypt`, `dotenv`

## 2. ความสามารถของระบบ

### ผู้ใช้ทั่วไป (User)

- สมัครสมาชิก เข้าสู่ระบบ และออกจากระบบ
- จัดการข้อมูลโปรไฟล์
- ดูรายการเกมและค้นหาเกม
- ค้นหาและกรองปาร์ตี้ตามคำค้น เกม เวลา สถานะ และจำนวนสมาชิก
- ดูรายละเอียดปาร์ตี้และรายชื่อสมาชิก
- สร้าง แก้ไข และลบปาร์ตี้ของตนเอง
- เข้าร่วมและออกจากปาร์ตี้
- ดูปาร์ตี้ที่สร้างหรือเข้าร่วม และประวัติที่เกี่ยวข้อง
- เจ้าของปาร์ตี้สามารถนำสมาชิกออกจากปาร์ตี้ของตนได้
- ระบบปิดรับสมาชิกเมื่อจำนวนสมาชิกครบตามที่กำหนด

### ผู้ดูแลระบบ (Admin)

- จัดการข้อมูลผู้ใช้และสิทธิ์ผู้ใช้
- เพิ่ม แก้ไข และลบข้อมูลเกม
- ดูและจัดการข้อมูลปาร์ตี้
- ลบปาร์ตี้ที่ไม่เหมาะสม

## 3. สิ่งที่ไม่อยู่ในขอบเขต

- แชตแบบ Real-time
- Voice Chat
- ระบบชำระเงิน
- ระบบการแข่งขันเกม
- การเชื่อมต่อกับเซิร์ฟเวอร์เกมโดยตรง
- ระบบจัดอันดับผู้เล่นแบบเกมจริง

## 4. สิ่งที่ต้องติดตั้งก่อนเริ่มใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org/)
2. ติดตั้ง [XAMPP](https://www.apachefriends.org/) หรือ MySQL Server
3. เปิด MySQL ให้ทำงาน
4. ใช้ phpMyAdmin หรือเครื่องมือจัดการ MySQL เพื่อสร้างฐานข้อมูล

## 5. วิธีติดตั้งและเริ่มใช้งาน

### ขั้นตอนที่ 1: สร้างฐานข้อมูล

1. เปิด XAMPP และกด **Start** ที่ MySQL
2. เปิด `http://localhost/phpmyadmin`
3. เลือกเมนู **Import**
4. เลือกไฟล์ `database/haparty.sql` ภายในโปรเจกต์ แล้วกด Import
5. ตรวจสอบว่ามีฐานข้อมูลชื่อ `haparty` และตารางถูกสร้างเรียบร้อยแล้ว

### ขั้นตอนที่ 2: ตั้งค่าตัวแปรแวดล้อม

สร้างไฟล์ชื่อ `.env` ไว้ในโฟลเดอร์เดียวกับ `server.js` โดยกำหนดค่าตาม MySQL ในเครื่องของคุณ ตัวอย่าง:

```env
PORT=3000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=haparty
DB_PORT=3306
SESSION_SECRET=ใส่ข้อความสุ่มที่คาดเดายากของคุณ
```

- หาก MySQL ของคุณมีรหัสผ่าน ให้ใส่รหัสผ่านนั้นใน `DB_PASSWORD`
- เปลี่ยน `SESSION_SECRET` เป็นข้อความสุ่มที่คาดเดายาก และอย่าเผยแพร่ไฟล์ `.env`
- อย่านำค่ารหัสผ่านหรือ Secret จริงใส่ไว้ใน README หรือส่งต่อให้ผู้อื่น

### ขั้นตอนที่ 3: ติดตั้งแพ็กเกจ

เปิด Terminal หรือ PowerShell ในโฟลเดอร์ที่มี `package.json` แล้วรัน:

```bash
npm install
```

### ขั้นตอนที่ 4: เปิดเซิร์ฟเวอร์

```bash
npm start
```

เมื่อเซิร์ฟเวอร์เริ่มทำงาน ให้เปิดเบราว์เซอร์ไปที่:

`http://localhost:3000`

หากต้องการตรวจสอบสถานะ API สามารถเปิด:

`http://localhost:3000/api/health`

หากเห็นผลลัพธ์ JSON ที่มี `"ok": true` แสดงว่าเซิร์ฟเวอร์ตอบสนองแล้ว ทั้งนี้ควรตรวจสอบการเชื่อมต่อฐานข้อมูลและทดสอบฟังก์ชันผ่านหน้าเว็บด้วย

## 6. การกำหนดบัญชี Admin

1. สมัครบัญชีผู้ใช้ผ่านหน้าเว็บก่อน
2. เปิด phpMyAdmin แล้วเลือกฐานข้อมูล `haparty`
3. เปิดแท็บ SQL และรันคำสั่งด้านล่าง โดยเปลี่ยน `ชื่อผู้ใช้ของคุณ` เป็นชื่อบัญชีที่สมัครไว้

```sql
UPDATE users
SET role = 'admin'
WHERE username = 'ชื่อผู้ใช้ของคุณ';
```

4. ออกจากระบบและเข้าสู่ระบบใหม่ เพื่อให้ระบบโหลดสิทธิ์ล่าสุด

**หมายเหตุ:** ใช้คำสั่งนี้เฉพาะกับฐานข้อมูลของโปรเจกต์ที่คุณดูแล และกำหนดสิทธิ์ Admin ให้เฉพาะบัญชีที่ได้รับอนุญาตเท่านั้น

## 7. โครงสร้างไฟล์สำคัญ

```text
HaParty/
├── database/
│   └── haparty.sql       # ไฟล์ SQL สำหรับสร้างฐานข้อมูลและตาราง
├── public/
│   ├── index.html        # หน้าหลัก
│   ├── auth.html         # หน้าสมัครสมาชิก/เข้าสู่ระบบ
│   ├── create-party.html # หน้าสร้างปาร์ตี้
│   ├── party.html        # หน้ารายละเอียดปาร์ตี้
│   ├── my-parties.html   # หน้าปาร์ตี้ของฉัน
│   ├── profile.html      # หน้าโปรไฟล์
│   ├── admin.html        # หน้าผู้ดูแลระบบ
│   ├── *.js              # JavaScript สำหรับการทำงานของแต่ละหน้า
│   └── style.css         # รูปแบบและการจัดวางหน้าเว็บ
├── db.js                 # การเชื่อมต่อ MySQL
├── server.js             # Express server และ API
├── package.json          # รายการแพ็กเกจและคำสั่ง
├── package-lock.json     # เวอร์ชันแพ็กเกจที่ติดตั้ง
└── .env                  # ค่าตั้งค่าส่วนตัว (ไม่ควรเผยแพร่)
```

## 8. คำสั่งที่ใช้บ่อย

```bash
npm install  # ติดตั้งแพ็กเกจ
npm start    # เริ่มเซิร์ฟเวอร์
npm run dev  # เริ่มเซิร์ฟเวอร์ด้วย nodemon
```

## 9. ข้อควรทราบก่อนส่งโปรเจกต์

- ต้องมีไฟล์ฐานข้อมูล `database/haparty.sql` และคำแนะนำการตั้งค่าเพื่อให้ผู้อื่นติดตั้งได้
- ไม่ควรส่งไฟล์ `.env` ที่มีรหัสผ่านหรือ Secret จริง ให้ผู้รับสร้างไฟล์ `.env` ของตนเองตามตัวอย่างในหัวข้อที่ 5
- ไม่จำเป็นต้องแนบโฟลเดอร์ `node_modules` หากผู้รับสามารถรัน `npm install` ได้
- ควรทดสอบสมัครสมาชิก เข้าสู่ระบบ/ออกจากระบบ การสร้างและเข้าร่วมปาร์ตี้ สิทธิ์ของเจ้าของปาร์ตี้ และสิทธิ์ Admin ก่อนส่ง
- การตรวจสอบว่าเซิร์ฟเวอร์เริ่มทำงานได้ ไม่ได้ยืนยันว่าทุกฟังก์ชันทำงานถูกต้อง ต้องทดสอบผ่านหน้าเว็บและฐานข้อมูลด้วย
